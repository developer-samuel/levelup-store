# 🏗️ Frontend: Build Scripts

This file documents all build-related frontend scripts defined in root `package.json`.  
Each command runs across both apps (ecommerce + assistant).

---

### dev

- **Command**: `pnpm dev`
- **Purpose**: Starts Vite development servers for both apps with HMR (Hot Module Replacement).

---

### build

- **Command**: `pnpm build`
- **Purpose**: Production build for both apps via Vite.
