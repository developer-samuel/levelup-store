# 🧪 Frontend: Test Scripts

This file documents all frontend test frontend scripts defined in `package.json`.

---

### vitest

- **Command**: `pnpm vitest`
- **Purpose**: Runs all Vitest unit tests once with coverage report generated.

---

### vitest:watch

- **Command**: `pnpm vitest:watch`
- **Purpose**: Runs Vitest in watch mode - re-runs affected tests on file changes.

---

### vitest:ui

- **Command**: `pnpm vitest:ui`
- **Purpose**: Opens the Vitest UI in the browser with coverage - interactive test explorer.
