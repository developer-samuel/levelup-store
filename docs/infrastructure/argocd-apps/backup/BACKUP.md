## velero

Kubernetes backup to OCI Object Storage.

**Namespace:** `velero`

| Command                         | Description                  |
|---------------------------------|------------------------------|
| `velero-start/down/stop/unsync` | Lifecycle                    |
| `velero-status/sync/pods/logs`  | Status                       |
| `velero-backups`                | List all backups with status |
| `velero-schedules`              | List backup schedules        |
