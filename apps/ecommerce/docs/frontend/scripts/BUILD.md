# 🏗️ Frontend: Build Scripts

This file documents all build-related frontend scripts defined in `package.json`.

---
```bash
cd apps/ecommerce
```


### dev

- **Command**: `pnpm dev`
- **Purpose**: Starts the Vite development server with HMR (Hot Module Replacement).

---
```bash
cd apps/ecommerce
```


### build

- **Command**: `pnpm build`
- **Purpose**: Compiles and bundles all assets for production via Vite.

---
```bash
cd apps/ecommerce
```


### watch

- **Command**: `pnpm watch`
- **Purpose**: Starts Vite in watch mode - rebuilds on file changes without starting the dev server.
