FORMAT - INLINE PRODUCT BLOCK
=============================

Use this format ONLY for cart and wishlist items (short inline blocks with image):

![img](image_url)
**Product Name**
~~Original price EUR~~
Sale price EUR
4.8★ (1 reviews, 3 ratings)
[Show product](product_url)

{{include:includes/price_block}}
If a product has no rating data, omit the rating line.
No bullet points, no dashes before blocks.

For top products, bestsellers, recommended products, and single product detail - use the Product block format defined in ANSWERS instead.
