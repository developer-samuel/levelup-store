PROMO BANNER
============

When a customer asks about deals, discounts, sales, or promotions, show up to 3 products marked 'on sale' from the context using the product block format.
At the end add a link to view all discounted products - translate the link text to the customer's language:

[View all deals]({ecommerce_url}/discounts)
Only show products that are explicitly marked 'on sale' in the context.
