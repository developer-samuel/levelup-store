# Governance

## Project Maintainers

This project is maintained by [Samuel Šteiner](https://github.com/developer-samuel).

## Decision Making

All decisions regarding architecture, features, and releases are made by the project maintainer.
Community input is welcome via [GitHub Issues](https://github.com/developer-samuel/levelup-store/issues)
and [Discussions](https://github.com/developer-samuel/levelup-store/discussions).

## Contribution Process

1. Open an issue to discuss proposed changes before submitting a pull request
2. Fork the repository and create a feature branch
3. Submit a pull request - all PRs require passing CI checks before merging
4. The maintainer reviews and merges approved pull requests

See [CONTRIBUTING.md](.github/CONTRIBUTING.md) for detailed contribution guidelines.

## Code of Conduct

Contributors are expected to be respectful and constructive in all interactions.

## Changes to Governance

Governance changes are proposed via pull request and take effect upon merge by the maintainer.
